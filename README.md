# DAO Treasury Contract

A treasury management contract that securely stores protocol funds and allows
governance-approved disbursements and allocations.

## Key Functions
- `deposit` — Add funds to the DAO treasury
- `propose-spend` — Submit a spending request
- `approve-spend` — Governance approval for fund usage
- `execute-spend` — Release funds after approval
- `get-balance` — View current treasury holdings

Designed for DAOs requiring transparent, auditable, and rule-based fund
management.
